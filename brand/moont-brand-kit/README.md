# Brand Kit Moont

Fonte central da identidade da Moont para produto, comunicação, apresentações,
parcerias e produção de novas peças.

## Conteúdo

| Pasta | O que contém |
| --- | --- |
| `design-system/` | tokens, tipografia, espaçamento, componentes e regras de interface |
| `identidade/` | essência, posicionamento, arquitetura de produtos e linguagem visual |
| `tom-de-voz/` | princípios editoriais, vocabulário, exemplos e checklist de revisão |
| `logos/` | kit completo em SVG e PNG, versões para fundo claro, escuro e uma cor |
| `artes/editorial/` | imagens editoriais aprovadas para comunicação institucional |
| `artes/campanhas/` | narrativas visuais e campanhas aprovadas |
| `artes/produto/` | capturas e demonstrações atuais do produto |

## Essência da marca

**Moont é a plataforma que transforma contexto em narrativas visuais.**

- Posicionamento: plataforma de narrativas visuais para comunicação e apresentações.
- Promessa: **Ideias que ganham forma. Histórias que movem.**
- Princípio de produto: **conteúdo com direção.**
- Assinatura curta: **ideias em movimento.**

## Uso rápido

1. Leia `identidade/identidade-completa.md` antes de criar uma nova campanha.
2. Use `design-system/tokens.json` como fonte para cores e medidas.
3. Escolha o logo pelo fundo; não recolora arquivos prontos.
4. Consulte `tom-de-voz/tom-de-voz.md` antes de publicar qualquer texto.
5. Use as artes desta pasta como referência de qualidade e direção, não como
   template obrigatório para toda peça.

## Regra de atualização

Alterações estruturais de marca devem ser registradas primeiro nesta pasta e
depois aplicadas ao produto. Novas artes entram apenas quando aprovadas e devem
ter nome descritivo, formato final e nenhuma marca de ferramenta ou texto
acidental gerado na imagem.
